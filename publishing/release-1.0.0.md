# String Duper Fix 1.0.0

Initial public release.

- Restores controlled tripwire string farms on modern Paper servers.
- Supports pistonless lever builds with bounded, event-driven checks.
- Adds `/stringduper` live controls, persistent per-player sounds, and safe reloads.
- Uses English by default and follows German, French, or Spanish player locales.
- Ships as one server-side JAR for Minecraft 1.21.2 through 26.3 on Paper-compatible servers.
- Contains no telemetry, network requests, NMS, reflection, or dependencies.
